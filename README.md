## IA-Express

The `IA-Express` directory contains the Salesman REST API as a standalone Node.js/Express subproject. It is separate from the Java/Maven build.

To run it, open a terminal in `IA-Express` and execute:

```powershell
npm install
npm start
```

The API listens on `http://localhost:3000`; its OpenAPI specification and Postman collection are included in that directory.
